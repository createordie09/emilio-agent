# Références visuelles — Iroko Mémoire

Ces images définissent l'univers visuel de l'application. La règle d'interprétation est dans `docs/CAHIER_DES_CHARGES.md`, §6.1.

- `originaux/` : les 5 maquettes complètes (REF-A à REF-E), pour l'ambiance générale.
- `extraits/` : 17 composants recadrés et agrandis (×2), nommés par code (ex. `C3_panneau-info-droite.png` = référence C, extrait 3).

| Code | Ce qu'on en retient |
|---|---|
| REF-A | Accent violet, bannière de bienvenue 3D, cartes KPI, cartes d'action, panneau de notices |
| REF-B | Barre latérale claire, accueil centré, composer, suggestions |
| REF-C | Fil d'Ariane, grille de cartes dossiers, panneau d'infos à droite |
| REF-D | Zone de dépôt, ligne de fichier avec progression, boutons pilules |
| REF-E | Fond dégradé doux, actions rapides, composer, panneau historique, carte utilisateur en verre |

Rappels :
- Ce sont des inspirations de style. Ne reprendre ni les textes, ni les marques, ni les logos, ni les photos, ni le personnage 3D.
- Une seule couleur d'accent : le violet (le bleu de REF-C et REF-D est transposé en violet).
- Pas de bouton « Upgrade / Pro » : l'application est gratuite.
